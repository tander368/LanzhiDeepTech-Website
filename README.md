## 项目简介

Lanzhi DeepTech Website 是一个 AI 辅助开发的企业官网模板项目，页面主题为工业 AI 与智能制造。网站整体采用单页结构，覆盖一家科技公司官网常见的核心内容，包括首页 Banner、核心产品、行业解决方案、客户案例、公司介绍、创始人故事、招聘信息、预约 Demo、白皮书下载和职位申请弹窗等模块。

该项目不是简单的静态展示页，而是尝试模拟真实 AI 科技公司官网的完整信息架构和商业转化路径。通过这个项目，可以展示 AI 在前端页面搭建、企业文案生成、产品介绍设计和开源项目文档整理中的辅助能力。

## 核心功能

### 1. 企业官网首页

首页使用 “Give Every Production Line Its Own Brain” 作为核心标语，突出工业 AI 赋能生产线的主题。页面展示了智能产线、制造业客户和行业覆盖等数据，让网站更接近真实 B2B 科技公司的展示方式。

### 2. 产品展示模块

网站设计了三条主要产品线：

- **LanEye · Visual Inspection System**  
  面向工业生产线的视觉质检系统，用于识别划痕、凹陷、错装等缺陷。

- **LanCe · Intelligent Scheduling Platform**  
  面向制造业的智能排产与预测平台，用于优化生产计划、提升产能利用率。

- **LanYu · Enterprise Knowledge Assistant**  
  面向企业内部知识管理的大模型助手，可连接 CRM、ERP 和文档系统，帮助员工进行知识查询和决策支持。

### 3. 行业解决方案

页面包含多个工业和商业场景解决方案，例如：

- 汽车零部件智能质检
- 消费电子精密检测
- 零售连锁智能运营
- 柔性生产智能排产

这些模块模拟了真实企业官网中“产品 + 行业场景 + 业务价值”的展示逻辑。

### 4. 客户案例展示

网站包含多个客户案例卡片，用于展示不同产品在制造业、消费电子和零售场景中的落地效果。案例模块可以帮助访问者更直观地理解产品应用方式。

### 5. 公司介绍与创始人故事

About 模块介绍了 Lanzhi DeepTech 的公司定位、团队背景和发展方向。页面还加入了创始人故事和 Founder’s Message，让网站不仅有产品介绍，也具备一定的品牌叙事感。

### 6. 招聘模块

Careers 模块展示了多个岗位，包括算法工程师、大模型应用工程师、工业产品经理和解决方案架构师等，使网站结构更接近真实科技公司的官网。

### 7. 表单交互

页面包含多个弹窗交互：

- Book a Demo
- Download Whitepaper
- Apply for Position

这些交互模拟了真实官网中的用户转化流程，适合作为企业落地页或创业项目 Demo 的基础模板。
